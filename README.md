# 월급계산소

직장인 돈 계산기 모음 (연봉 실수령액, 퇴직금, 주휴수당, 실업급여, 연차). 서버 없이 동작하는 정적 사이트입니다.

## 구조
- `src/pages/*.html`: 페이지 본문. 맨 위 주석에 제목, 설명, 주소를 적습니다.
- `assets/calc.js`: 계산 공식과 2026년 기준값(`RATES`). 요율이 바뀌면 여기만 고칩니다.
- `site.config.json`: 사이트 이름, 도메인, 연락 메일, 애드센스 ID.
- `build.mjs`: `node build.mjs`를 실행하면 `public/`에 완성된 사이트가 만들어집니다.

## 배포
Cloudflare Pages에서 이 저장소를 연결하고 빌드 명령 `node build.mjs`, 출력 폴더 `public`으로 설정합니다.

- 7월: 국민연금 기준소득월액 상한·하한
